# CHIROMBE MATRIX 3.0

Standalone duplicate of the CHIROMBE command surface.

The original repository at https://github.com/tariromasawi/chirombe stays the archive.
This package is the reconstruction: a thin, fault-isolated frontend plus a live kernel that already implements the public APIs.

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` → `/` (root).

Expected URL:

https://tariromasawi.github.io/chirombe-matrix/

`index.html` is at the repository root.

## Boot

Two scripts only:

- `js/matrix-kernel.js`
- `js/matrix-shell.js`

The historical `chirombe engine` artifact is not executed.
